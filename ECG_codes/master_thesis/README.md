# Benchmarking Explainable AI Methods for ECG Classification Using Perturbation-Based Faithfulness Evaluation

This repository contains the code for my MSc thesis, *Benchmarking Explainable AI Methods for
ECG Classification Using Perturbation-Based Faithfulness Evaluation*. Two deep learning
architectures are trained on the **PTB-XL** dataset (100 Hz, 12-lead) and evaluated on two tasks:
a **five-class** diagnostic-superclass task (`CD, HYP, MI, NORM, STTC`) and a **binary
NORM-versus-MI** task (`NORM = 0, MI = 1`). Model predictions are explained with three attribution
methods — Integrated Gradients (IG), SmoothGrad-IG, and Deep Taylor Decomposition (DTD) — and the
methods are **benchmarked by their explanation faithfulness** using an attribution-guided
perturbation benchmark, complemented by statistical analyses (bootstrap confidence intervals,
Wilcoxon signed-rank tests, and Bland–Altman agreement).

**Architectures**
- CNN (Deeper CNN)
- CNN–BiLSTM with Attention

**Attribution methods**
- Integrated Gradients (IG)
- SmoothGrad-IG
- Deep Taylor Decomposition (DTD)

**Evaluation**
- Attribution-guided perturbation benchmark (segment- and timestep-level; zero-out and interpolation)
- Statistical analysis: bootstrap confidence intervals, Wilcoxon signed-rank tests
- Bland–Altman agreement analysis

## 1. Project contributions

The repository implements the following, verified from the current source files:

- Preprocessing of raw PTB-XL into model-ready arrays (band-pass filtering, per-lead z-scoring).
- Five-class and binary NORM-versus-MI dataset preparation.
- Training of the Deeper CNN and the CNN–BiLSTM with Attention.
- Evaluation of trained checkpoints (Accuracy, Macro F1, ROC-AUC / Macro AUC, Average Precision).
- Attribution generation with IG, SmoothGrad-IG, and DTD.
- Segment-level and timestep-level perturbation of ranked ECG regions.
- Zero-out and interpolation perturbation strategies, with matched random-order baselines.
- Bootstrap confidence intervals and Wilcoxon signed-rank tests on perturbation AUC.
- Bland–Altman agreement analysis (all-sample and MI-only variants).
- Figure and table generation for the classification and XAI results.
- Export of per-seed prediction probabilities for the multi-seed classification analysis.

## 2. Repository structure

```
master_thesis/
├── requirements.txt
├── data/processed/      # meta.json only — the .npy arrays are regenerated by preprocess*.py (see §4)
├── src/                 # preprocessing, training, evaluation, and plotting scripts
```

> **Submission note.** To keep the archive small, the preprocessed PTB-XL arrays
> (`data/processed/*/X_*.npy`, `y_*.npy`) and the trained model checkpoints (`best.pt`) are
> **not bundled** in this submission. Both are fully regenerable from the code that *is* included:
> the arrays via the preprocessing scripts (Section 4) from the public PTB-XL dataset, and the
> checkpoints by retraining with the fixed seeds (Section 5). The small `meta.json` files, the
> result summaries/reports (`final_report.txt`, `bland_altman_report.txt`, `metrics_test.json`,
> `train_config.json`, completeness summaries, aggregated CSVs) are included, so all reported
> numbers can be inspected directly without re-running anything.
>
> **Figures.** The attribution/perturbation heatmaps, Bland–Altman plots, and the perturbation
> curve-grid figure that appear in the thesis **are** included. The **classification summary
> figures** (multi-seed ROC/PR curves and performance boxplots) are **not bundled** to save
> space; they regenerate from the included per-seed prediction arrays
> (`result/figures_*_10seed/predictions/*.npy`) via the `plot_*` scripts (Section 6).

**Preprocessing** (`preprocess.py`, `preprocess_binary.py`) converts the raw PTB-XL recordings
into the model-ready arrays stored under `data/processed/`, one folder for the five-class task
and one for the binary NORM-versus-MI task.

**Training** (`train_cnn.py`, `cnn_lstm_attn.py`) trains the Deeper CNN and the CNN–BiLSTM with
Attention. Each run writes its checkpoint (`best.pt`) and configuration to a seed-specific folder
under `result/`.

**Evaluation** (`eval_cnn.py`, `eval_cnn_lstm.py`) loads a checkpoint, runs inference on the test
split, and writes the classification metrics. The multi-seed figure and table scripts in `src/`
aggregate these results across the ten seeds.

**XAI benchmark** (the `xai_benchmark` package, run via `python -m xai_benchmark.main`) computes
the IG, SmoothGrad-IG, and DTD attributions, perturbs the ranked ECG regions, and evaluates
explanation faithfulness. It also contains the Bland–Altman analysis and the attribution/curve
plotting scripts.

**Results.** `result/` holds the classification checkpoints and the classification figures and
tables, while `results/` holds the XAI benchmark outputs (attributions, perturbation curves,
completeness checks, and Bland–Altman reports).

## 4. Data preparation

The raw **PTB-XL** dataset (PhysioNet, 12-lead) must be downloaded separately and passed to the
preprocessing scripts via `--data_root`. The scripts write the processed arrays to
`data/processed/`:

```bash
cd src
python preprocess.py        --data_root <path-to-raw-PTB-XL> --out_dir ../data/processed/ptbxl_lr_5class
python preprocess_binary.py --data_root <path-to-raw-PTB-XL> --out_dir ../data/processed/ptbxl_lr_binary_norm_mi
```

Both scripts additionally accept `--max_train`, `--max_val`, `--max_test` (sample caps) and the
band-pass parameters `--low`, `--high`, `--order`. The processed folders contain the
`X_{train,val,test}.npy`, `y_{train,val,test}.npy`, and `meta.json` files used downstream.
(The exact raw PTB-XL download URL/version is **Not verified** from the repository.)

## 5. Running the classification experiments

All commands are run from `src/`. Seeds used for the final results: `42, 123, 777, 2024, 9999,
47, 48, 49, 50, 51`.

### 5.1 Five-class — CNN (Deeper CNN)
```bash
python train_cnn.py --data_dir ../data/processed/ptbxl_lr_5class \
  --out_dir ../result/cnn_final/deeper_cnn_seed_42 \
  --arch deeper --num_classes 5 --epochs 20 --batch_size 128 --lr 1e-3 \
  --weight_decay 1e-4 --dropout 0.2 --grad_clip 1.0 --seed 42 --device cuda
```

### 5.2 Five-class — CNN–BiLSTM with Attention
```bash
python cnn_lstm_attn.py --data_dir ../data/processed/ptbxl_lr_5class \
  --out_dir ../result/cnn_lstm_attn_weighted_final/cnn_lstm_attn_weighted_42 \
  --epochs 20 --batch_size 128 --lr 1e-3 --weight_decay 1e-4 --dropout 0.3 \
  --lstm_hidden 64 --attn_hidden 64 --use_class_weights --grad_clip 1.0 --seed 42 --device cuda
```

### 5.3 Binary — CNN (Deeper CNN)
```bash
python train_cnn.py --data_dir ../data/processed/ptbxl_lr_binary_norm_mi \
  --out_dir ../result/binary_experiment/cnn_deeper/cnn_deeper_binary_seed_42 \
  --arch deeper --num_classes 2 --epochs 20 --batch_size 128 --lr 1e-3 \
  --weight_decay 1e-4 --dropout 0.2 --grad_clip 1.0 --seed 42 --device cuda
```

### 5.4 Binary — CNN–BiLSTM with Attention (unweighted)
```bash
python cnn_lstm_attn.py --data_dir ../data/processed/ptbxl_lr_binary_norm_mi \
  --out_dir ../result/binary_experiment/cnn_lstm_binary/cnn_lstm_binary_seed_42 \
  --epochs 20 --batch_size 128 --lr 1e-3 --weight_decay 1e-4 --dropout 0.3 \
  --lstm_hidden 64 --attn_hidden 64 --grad_clip 1.0 --seed 42 --device cuda
```

Repeat each command for every seed. Evaluation (writes `metrics_test.json` next to the checkpoint):
```bash
python eval_cnn.py      --data_dir <data> --ckpt <path>/best.pt --split test --num_classes {2|5} --arch deeper --save_txt
python eval_cnn_lstm.py --data_dir <data> --ckpt <path>/best.pt --split test --num_classes {2|5} --dropout 0.3 --lstm_hidden 64 --attn_hidden 64 --save_txt
```
*(`train_cnn.py` takes `--num_classes`; `cnn_lstm_attn.py` infers the class count from the data.)*

## 6. Multi-seed evaluation

The final classification results are aggregated across the ten seeds. For each task, the
`export_*` script runs inference and saves the per-seed probabilities, and the `plot_*` scripts
then produce the metric boxplots, the mean ROC and Precision–Recall curves, and the summary tables.

```bash
# five-class
python export_5class_10seed_probs.py
python plot_figure25_2x2_10seeds.py
python plot_5class_10seed_roc_pr.py

# binary
python export_binary_10seed_probs.py
python plot_binary_10seed.py
```
The export scripts read the checkpoints in `result/cnn_final/`, `result/cnn_lstm_attn_weighted_final/`,
and `result/binary_experiment/`, and write predictions and figures under `result/figures_5class_10seed/`
and `result/figures_binary_10seed/`.

## 7. Running the XAI perturbation benchmark

The benchmark is driven by `xai_benchmark/main.py`. It computes IG, SmoothGrad-IG, and DTD
attributions, ranks ECG regions, perturbs them stepwise (zero-out and interpolation) at both
segment- and timestep-level granularity, and records the perturbation AUC against a matched
random-order baseline.

```bash
python -m xai_benchmark.main \
  --data_dir ../data/processed/ptbxl_lr_binary_norm_mi \
  --cnn_ckpt  ../result/binary_experiment/cnn_deeper/cnn_deeper_binary_seed_42/best.pt \
  --lstm_ckpt ../result/binary_experiment/cnn_lstm_binary/cnn_lstm_binary_seed_42/best.pt \
  --out_dir  ../results --num_classes 2 --target_class 1 --ig_steps 50
```

Selectable subsets (verified CLI arguments):
```
--methods        ig smoothgrad_ig dtd
--perturbations  zero_out interpolation
--granularities  segment timestep
--models_to_run  cnn cnn_lstm
```
Additional arguments include `--sg_samples`, `--edge_mask`, `--max_samples`, `--max_norm_samples`,
`--synth_method`, `--seed`, `--random_seed`, `--split`.

**Segment-level is the primary benchmark reported in the thesis; the timestep-level benchmark is
supplementary.** Both are produced by the same command via `--granularities`.

## 8. Bland–Altman analysis

```bash
python -m xai_benchmark.bland_altman \
  --ig_results_dir ../results/IG \
  --smoothgrad_results_dir ../results/smoothgrad \
  --dtd_results_dir ../results/dtd \
  --out_dir ../results/bland_altman

python -m xai_benchmark.bland_altman_mi_only     # MI-only comparisons
python -m xai_benchmark.plot_method_curves_grid  # perturbation curve-grid figure
```
`bland_altman.py` produces the agreement statistics between attribution methods, perturbation
strategies, and architectures; `bland_altman_mi_only.py` restricts the interpolation-versus-zero-out
comparison to MI samples. (The CLI of `bland_altman_mi_only.py` and `plot_method_curves_grid.py`
uses fixed input/output paths; command-line arguments are **Not verified**.)

## 13. Reproducibility notes

- **Splits:** training uses the processed `train`/`val` arrays; all reported metrics are computed
  on the held-out `test` split.
- **Seeds:** each run sets its seed explicitly; the ten-seed list is
  `42, 123, 777, 2024, 9999, 47, 48, 49, 50, 51`. Classification results (Tables 3–4, Figures 25–28)
  are aggregated across these ten seeds.
- **Checkpoint naming:** `<experiment>_seed_<seed>/best.pt`. For the binary Deeper CNN, seeds
  `42,123,777,2024,9999` are stored under `binary_experiment/cnn_deeper/` and seeds `47–51` under
  `binary_experiment/cnn_binary/` (both are the deeper architecture).
- **`result/` vs `results/`:** `result/` holds classification checkpoints and classification
  figures/tables; `results/` holds the XAI benchmark outputs (attributions, perturbation curves,
  Bland–Altman, completeness).
- **Representative-seed analyses:** the XAI perturbation and attribution analyses use the seed-42
  binary checkpoints as the representative models.
